# FrameCove CAN™

> CAN / CAN FD 로그를 분석하는 Windows 데스크톱 도구입니다. 로그와 프로토콜 정의를 가져오고 신호를 선택하면 오프라인 공유가 가능한 대화형 HTML 보고서를 생성합니다.

[**Windows V1.4.2 다운로드**](https://github.com/hsj521/FrameCove-CAN-Releases/releases/download/v1.4.2/FrameCove_CAN_Setup_1.4.2.exe) · [모든 릴리스](https://github.com/hsj521/FrameCove-CAN-Releases/releases)

## 주요 기능

- 로그, 프로토콜 파일, 보고서를 로컬 PC에서 처리하며 업무 데이터를 업로드하지 않습니다.
- ASC / BLF, DBC / XLSX 디코딩, CAN 1~8 선택 및 일반적인 CAN FD 로그를 지원하며, 기록 장치별 BLF 시간 보정과 대용량 로그 고속 분석을 제공합니다.
- 독립 색상 Y축, 공통 시간축, 2점 측정 및 샘플 포인트 확인을 제공합니다.
- 로컬 보고서에서는 메모를 편집할 수 있으며 읽기 전용 협업 보고서는 그래프 보기, 확대/축소, 호버, 저장된 메모와 시간을 유지합니다. 보고서에는 `FrameCove CAN™ · V1.4.2`이 표시됩니다.
- HTTPS로 업데이트를 확인하고 다운로드한 설치 프로그램의 SHA-256을 검증합니다.

## 설치

1. [`FrameCove_CAN_Setup_1.4.2.exe`](https://github.com/hsj521/FrameCove-CAN-Releases/releases/download/v1.4.2/FrameCove_CAN_Setup_1.4.2.exe)를 다운로드합니다.
2. 설치 프로그램을 실행하고 안내에 따릅니다.
3. 실행 중인 FrameCove CAN 또는 이전 AutoX CAN은 파일 교체 전에 설치 프로그램이 종료합니다.

체크섬과 릴리스 노트는 [V1.4.2 Release 페이지](https://github.com/hsj521/FrameCove-CAN-Releases/releases/tag/v1.4.2)에서 확인할 수 있습니다.

이 저장소에는 설치 프로그램, 릴리스 노트 및 체크섬만 포함되며 FrameCove CAN 소스 코드는 포함되지 않습니다. `FrameCove CAN™`은 등록되지 않은 표식입니다.
