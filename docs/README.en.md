# FrameCove CAN™

> A Windows desktop tool for CAN / CAN FD log analysis. Import a log and protocol definition, select signals, and create an interactive HTML report that can be shared and opened offline.

[**Download Windows V1.4.2**](https://github.com/hsj521/FrameCove-CAN-Releases/releases/download/v1.4.2/FrameCove_CAN_Setup_1.4.2.exe) · [All releases](https://github.com/hsj521/FrameCove-CAN-Releases/releases)

## Highlights

- Local processing for logs, protocol files, and reports; no business data upload.
- ASC / BLF logs, DBC / XLSX decoding, CAN 1–8 selection, and common CAN FD records, with BLF timestamp calibration based on filename recording time and recorder type, plus faster large-file decoding.
- Independent colored Y-axes, shared timeline inspection, two-point measurement, and sample-point reading.
- Editable notes in local reports and read-only collaboration exports that preserve the graph view, zoom, hover, saved notes, and timestamps, branded `FrameCove CAN™ · V1.4.2`.
- HTTPS update checks with SHA-256 verification before launching a downloaded installer.
- Clear report-generation feedback: deep red percentage progress while processing, deep green at completion.

## Install

1. Download [`FrameCove_CAN_Setup_1.4.2.exe`](https://github.com/hsj521/FrameCove-CAN-Releases/releases/download/v1.4.2/FrameCove_CAN_Setup_1.4.2.exe).
2. Run the installer and follow the wizard.
3. The installer closes a running FrameCove CAN or legacy AutoX CAN process before replacing files.
