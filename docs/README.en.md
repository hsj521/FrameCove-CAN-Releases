# FrameCove CAN™

> A Windows desktop tool for CAN / CAN FD log analysis. Import a log and protocol definition, select signals, and create an interactive HTML report that can be shared and opened offline.

[**Download the latest Windows installer**](https://github.com/hsj521/FrameCove-CAN-Releases/releases/latest) · [All releases](https://github.com/hsj521/FrameCove-CAN-Releases/releases)

## Highlights

- Local processing for logs, protocol files, and reports; no business data upload.
- ASC / BLF logs, DBC / XLSX decoding, CAN 1–8 selection, and common CAN FD records, with BLF timestamp calibration based on filename recording time and recorder type, plus faster large-file decoding.
- Independent colored Y-axes, shared timeline inspection, two-point measurement, and sample-point reading.
- Editable notes in local reports and read-only collaboration exports that preserve the graph view, zoom, hover, saved notes, and timestamps.
- HTTPS update checks with SHA-256 verification before launching a downloaded installer.
- Clear report-generation feedback: deep red percentage progress while processing, deep green at completion.

## Install

1. Open the [latest release](https://github.com/hsj521/FrameCove-CAN-Releases/releases/latest) and download `FrameCove_CAN_Setup_*.exe` from Assets.
2. Run the installer and follow the wizard.

The installer’s SHA-256 checksum and release notes are on the [latest release page](https://github.com/hsj521/FrameCove-CAN-Releases/releases/latest).

This repository distributes installers, release notes, and checksums only. It does not contain FrameCove CAN source code. `FrameCove CAN™` is an unregistered mark; third-party marks belong to their respective owners.
