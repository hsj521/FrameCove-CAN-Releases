# FrameCove CAN™

> CAN / CAN FD ログを解析する Windows デスクトップツールです。ログとプロトコル定義を読み込み、信号を選択して、オフライン共有可能な対話型 HTML レポートを生成します。

[**最新版の Windows インストーラーを入手**](https://github.com/hsj521/FrameCove-CAN-Releases/releases/latest) · [すべてのリリース](https://github.com/hsj521/FrameCove-CAN-Releases/releases)

## 主な特長

- ログ、プロトコル、レポートをローカル PC 内で処理し、業務データをアップロードしません。
- ASC / BLF、DBC / XLSX、CAN 1～8、一般的な CAN FD ログに対応し、レコーダーに応じた BLF 時刻補正と大容量ログの高速解析を提供します。
- 独立した色付き Y 軸、共通タイムライン、2 点測定、サンプル点の確認を提供します。
- ローカルレポートでは注釈を編集でき、読み取り専用の共有レポートにはグラフ表示、ズーム、ホバー、保存済み注釈と時刻が保持されます。
- HTTPS で更新を確認し、ダウンロードしたインストーラーの SHA-256 を検証します。

## インストール

1. [最新リリース](https://github.com/hsj521/FrameCove-CAN-Releases/releases/latest)を開き、Assets から `FrameCove_CAN_Setup_*.exe` をダウンロードします。
2. インストーラーを実行し、画面の案内に従います。

インストーラーの SHA-256 チェックサムとリリースノートは[最新リリースページ](https://github.com/hsj521/FrameCove-CAN-Releases/releases/latest)で確認できます。

このリポジトリにはインストーラー、リリースノート、チェックサムのみを含み、FrameCove CAN のソースコードは含みません。`FrameCove CAN™` は未登録の標識です。
